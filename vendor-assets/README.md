# Operator Asset Packs

This directory is ignored except for this guide. Do not commit Mobile Legends: Bang Bang media unless its redistribution permission is documented.

An imported pack must provide a manifest containing:

- a stable asset ID and hero ID;
- the relative portrait and optional WebM/MP4 poster paths;
- source URL or agreement reference;
- copyright holder and license;
- SHA-256 checksum for each file.

The application falls back to original geometric placeholders when no licensed pack is installed.
